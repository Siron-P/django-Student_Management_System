# django-Student_Management_System
Django-based student management system with role-based access for Admin, Teacher, and Student — including attendance and results tracking.

## Status: In Progress

## Planned Features
- [✓] Role-based authentication (Admin / Teacher / Student)
- [✓] Gated student/teacher signup — must be pre-registered by admin before signing up
- [ ] Profile completion flow on first student login
- [ ] Admin: manage students, teachers, and courses
- [ ] Teacher: mark attendance, update results for their students
- [ ] Student: view profile, attendance, and results

## Tech Stack
- Python, Django
- SQLite (dev)
- Django templates + Bootstrap
